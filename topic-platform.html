Security, the Modern Web Platform & the Market

Today a browser is more than a page reader — it is a secure platform that can run full applications.

Browser Security

Because a browser runs code from websites you cannot fully trust, security is really important. Modern browsers use sandboxing: each tab runs in its own separate process, so if one page has a bug or a bad exploit it cannot easily mess up the rest of the browser or your computer.

Browsers also split the work into different processes (a browser process, renderer processes, a GPU process and a network process) and use memory safety. HTTPS is also important because it encrypts the connection, so your data cannot be read or changed while it is travelling to the server.

The Modern Web Platform

Browsers do not just act as page readers any more; they can be a platform for apps. Standards bodies add APIs so a web app can use the device and act like a normal app.

  • WebAssembly (Wasm) lets developers run compiled, almost-native code in the browser.
  • Service workers let a web app work offline and be installed like an app — these are called progressive web apps (PWAs).
  • Other APIs include the Geolocation API, access to the camera and microphone, and push notifications.

Because of this, a lot of things that used to need a downloaded app can now be done in a browser.

Recent Developments: Antitrust

Competition is a big conversation surrounding browsers today, given Chrome controls such a large portion of the market. In the US case United States v. Google (2020), a judge ruled in August 2024 that Google had an illegal monopoly in search and text advertising.

In September 2025, the court gave behavioural remedies. Google had to stop exclusive deals that make its search the default on devices, and it has to share some search data with its rivals. However, the court said Google did not have to sell Chrome.

Future Directions

  • AI in the browser — built-in AI helpers that can read a page, provide summaries, or complete tasks for the user are exploding in popularity.
  • Privacy — stronger defaults (blocking tracking, DNS-over-HTTPS, passkeys) keep changing how browsers are built.
  • Engine consolidation — almost every browser out now uses Chromium; Firefox and Safari are the only other competition.
  • WebAssembly & PWAs — the browser keeps becoming a platform for fast, offline apps.
  • Cross-platform — browsers are on phones, TVs and computers, and they are built into other apps too.
  • AI era — most AI services run in the browser.
