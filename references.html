Good Learning Resources

These are good beginner-friendly sources to learn more about how the web works.

  • MDN Web Docs — clear, official references for HTML, CSS and JavaScript.
  • web.dev — Google's guide to the modern web, including how browsers work.
  • W3C — the organization that sets many web standards.
  • WHATWG — the group behind the living HTML standard.
