What Is a Web Browser?

A web browser is the program most people use to get on the internet and look at websites. It is the main client in the web's client and server model. It asks a web server for a page over HTTP and then shows it to the user.

In this project I explain what a browser is and what it does, how it has changed over the years, and how it actually turns a web page into what ends up on your screen. I also look at the companies and people behind the main browsers, where the browser market is today, and what might happen next.

The browser has expanded beyond just a program that displays web pages. It is a platform that can run apps, store data, and interact with a user's hardware.
